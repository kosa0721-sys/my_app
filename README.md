# ゴルフスコア帳

スマホ向けのシンプルな18ホール・ゴルフスコア記録アプリです。  
コースマスタは不要で、各ホールの打数だけを記録・合計します。データは端末の `localStorage` に保存されます（オフライン可）。

## 開き方

このフォルダでローカルサーバーを起動するのがおすすめです（PWAのマニフェストも正しく読めます）。

```bash
cd golf-score-app
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。  
スマホで使う場合は、同じWi‑Fi上のPCのIP（例: `http://192.168.x.x:8080`）にアクセスします。

`index.html` を直接ダブルクリックで開いても動作します（一部ブラウザではファイル直開き時に制限がある場合があります）。

### ホーム画面に追加（PWA）

- **iPhone (Safari)**: 共有 →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「アプリをインストール」または「ホーム画面に追加」

## 主な機能

- 新規ラウンドは全ホール「未入力」から開始。打数を入れたホールだけを集計する
- 各ホールで PAR3 / PAR4 / PAR5 をタップ選択
- 「手入力」か「コース選択」。コース名で日本のスコアカードを検索し、PARとヤードを入れる。27/36ホールでエリアが分かれている場合は、プレーする組み合わせ（または2つの9ホール）を選ぶ
- 見つからない・ホールデータがないコースは、コース名だけ残して手入力に戻る
- 打数は 1〜10 のボタン、または「その他」で自由入力
- 合計 / PAR計 / 差 / OUT(1–9) / IN(10–18) は入力済みホールのみ（PAR計も入力済みホールだけ）
- プレー中は打数・PAR・日付・メモを自動保存。アプリを閉じても途中経過が残る
- ホームの「続きから入力」で、プレー中ラウンドの最初の未入力ホールから再開
- 18ホール入力で自動的に「完了」。途中で「プレーを完了にする」こともできる
- ラウンド日・メモ（任意）
- 過去ラウンドの一覧・詳細・編集・削除（プレー中 / 完了を表示）
- 端末内保存（localStorage）。更新前に保存したラウンドは完了・全ホール入力済みとして読み込む
- スコア記録の Markdown 書き出し（1ラウンド / 全履歴）。未入力ホールは「-」、入力ホール数を記載


## ファイル構成

- `index.html` … 画面
- `style.css` … モバイル向けスタイル
- `app.js` … ロジックと保存処理
- `course.js` … コース検索（GolfCore の公開API）

## コースデータ

ブラウザから [GolfCore](https://www.golfcore.org/) の公開API（`https://api.golfcore.org/v1`、CORS 可、APIキー不要）で日本のコースを検索し、公開されているスコアカードの PAR とヤードを入れます。表示時は GolfCore と OpenStreetMap のクレジットが必要です。

OpenStreetMap 単体では日本のホール PAR がほぼ無く（全国でパー付きホールは数十件）、楽天GORAなどはブラウザから直接呼べず秘密鍵も置けません。キーなし利用の期限は API の `Sunset` ヘッダ時点（2026-12-04）です。それ以降も検索を続けるには、無料の GolfCore キーを隠す小さなプロキシ（例: Cloudflare Worker）が必要です。キーをこの静的サイトに埋め込むと公開されてしまいます。
- `manifest.json` / `icons/` … ホーム画面追加用

## Markdown 書き出し（スコア記録）

アプリに保存した**スコアデータ**を `.md` ファイルとしてダウンロードできます。ソースコードではなく、ラウンドの記録を他のAIに渡す用途です。

- **一覧画面**:「全履歴を .md で書き出す」
- **詳細画面**:「このラウンドを .md で書き出す」

書き出される内容の例:
- 日付・メモ・合計 / PAR計 / 差 / OUT / IN
- ホールごとの表（ホール / サイド / PAR / 打数 / 差）

## ホーム画面にインストール（PWA）

HTTPS で配信し、Service Worker（`sw.js`）が有効な状態で Chrome の「アプリをインストール」が使えます。

**注意:** Netlify Drop のパスワード保護を付けていると、インストールできないことがあります。公開サイトか、保護なしで試してください。
