# ゴルフスコア帳

スマホ向けのシンプルな18ホール・ゴルフスコア記録アプリです。  
コースマスタは不要で、各ホールの打数だけを記録・合計します。データは端末の `localStorage` に保存されます（オフライン可）。

## 開き方

このフォルダでローカルサーバーを起動するのがおすすめです（PWAのマニフェストも正しく読めます）。

```bash
cd golf-score-app
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。  
スマホで使う場合は、同じWi‑Fi上のPCのIP（例: `http://192.168.x.x:8080`）にアクセスします。

`index.html` を直接ダブルクリックで開いても動作します（一部ブラウザではファイル直開き時に制限がある場合があります）。

### ホーム画面に追加（PWA）

- **iPhone (Safari)**: 共有 →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「アプリをインストール」または「ホーム画面に追加」

## 主な機能

- 新規ラウンド開始（デフォルト各ホール PAR4・4打）
- 各ホールで PAR3 / PAR4 / PAR5 をタップ選択
- 打数は 1〜10 のボタン、または「その他」で自由入力
- 合計 / PAR計 / 差 / OUT(1–9) / IN(10–18) の自動計算
- ラウンド日・メモ（任意）
- 過去ラウンドの一覧・詳細・編集・削除
- 端末内保存（localStorage）
- スコア記録の Markdown 書き出し（1ラウンド / 全履歴）— 他のAIに渡せる表形式


## ファイル構成

- `index.html` … 画面
- `style.css` … モバイル向けスタイル
- `app.js` … ロジックと保存処理
- `manifest.json` / `icons/` … ホーム画面追加用

## Markdown 書き出し（スコア記録）

アプリに保存した**スコアデータ**を `.md` ファイルとしてダウンロードできます。ソースコードではなく、ラウンドの記録を他のAIに渡す用途です。

- **一覧画面**:「全履歴を .md で書き出す」
- **詳細画面**:「このラウンドを .md で書き出す」

書き出される内容の例:
- 日付・メモ・合計 / PAR計 / 差 / OUT / IN
- ホールごとの表（ホール / サイド / PAR / 打数 / 差）

## ホーム画面にインストール（PWA）

HTTPS で配信し、Service Worker（`sw.js`）が有効な状態で Chrome の「アプリをインストール」が使えます。

**注意:** Netlify Drop のパスワード保護を付けていると、インストールできないことがあります。公開サイトか、保護なしで試してください。
